# Vrinda Store Data Analysis (Excel-Based Project)

This repository contains an Excel-based data analysis project for **Vrinda Store**. The project aims to derive insights from raw sales and customer data using Excel features such as formulas, pivot tables, charts, and conditional formatting.

---

## Project Overview

The analysis includes:

- Product-wise and category-wise sales tracking
- Monthly and yearly sales trends
- Inventory and stock movement analysis
- Customer purchase patterns
- Revenue and profit summaries

This project demonstrates how Excel can be effectively used to perform data cleaning, analysis, and visualization without the need for external tools or software.

---

## Files Included

- `Vrinda Store Data Analysis.xlsx`: The main Excel workbook containing:
  - Raw data sheets
  - Cleaned data tables
  - Pivot tables and summary dashboards
  - Charts and visual insights

---

## Tools Used

- **Microsoft Excel**
  - Pivot Tables
  - Charts (Bar, Line, Pie)
  - Data Validation
  - Conditional Formatting
  - Basic Formulas & Functions (SUMIFS, VLOOKUP, etc.)

---

## How to Use

1. Clone or download this repository.
2. Open `Vrinda Store Data Analysis.xlsx` using Microsoft Excel (preferably 2016 or later).
3. Explore different sheets to understand:
   - Raw vs. cleaned data
   - Sales analysis dashboards
   - Monthly performance trends

---

## Key Insights

- Best-selling product categories and months
- Revenue contribution by region or store
- High-spending customers
- Seasonal trends in sales
